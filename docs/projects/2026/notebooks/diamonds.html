Analyzing these plots, it would appear the variable with the strongest correlation to price is carat, as well as the dimensional variables x, y, and z, which makes sense given that carat is after all a measure of the diamonds weight.

The boxplots of cut, color, and clarity all show the opposite of what I would have expected, generally lower median prices as you move along the categories from worst to best. More notable than that though is that each category of each variable contains a large number of outliers, reaching up to the highest prices points.

Another notable observation is that there’s slightly more variation in depth, and to a lesser extent, table, at the lower prices than there is at higher prices. This is consistent with what I’ve read that there is an ideal central range of ratios for these.

def get_evar_avgs(evar_list, training_df, cat_cols):
    avg_vals = []
    for col in evar_list:
        if col not in cat_cols:
            avg_val = training_df[col].mean()
        else:
            avg_val = training_df[col].mode().values[0]
        avg_vals.append(avg_val)
    output = {col: val for col, val in zip(evar_list, avg_vals)}
    return output

def get_evar_avgs(evar_list, training_df, cat_cols):
    avg_vals = []
    for col in evar_list:
        if col not in cat_cols:
            avg_val = training_df[col].mean()
        else:
            avg_val = training_df[col].mode().values[0]
        avg_vals.append(avg_val)
    output = {col: val for col, val in zip(evar_list, avg_vals)}
    return output

def get_ci(input_df, mpipe, sm_model, percent):
    '''
    Provide a trained statsmodels.OLS model and a specified alpha to generate confidence interval.

    Parameters:
        input_df: dataframe contained encoded predictions
        mpipe: sklearn pipeline container transformers and model
        sm_model: statsmodels.OLS trained model
        alpha: 0-1

    '''
    col_transformer = mpipe[:-1]
    x_vals_encoded = col_transformer.transform(input_df)
    
    if type(x_vals_encoded) != np.ndarray:
        x_vals_encoded = x_vals_encoded.toarray()
    xc = sm.add_constant(x_vals_encoded, has_constant='add')
    xc_feature_names = ['intercept'] + list(col_transformer.get_feature_names_out())
    xc_df = pd.DataFrame(xc, columns=xc_feature_names)

    sm_pred = (sm_model.get_prediction(xc_df).summary_frame(alpha=(1-percent)))

    sm_log_mean = sm_pred['mean'].values[0]
    sm_log_ci_low = sm_pred['obs_ci_lower'].values[0]
    sm_log_ci_up = sm_pred['obs_ci_upper'].values[0]
    sm_log_se = (sm_log_ci_up - sm_log_mean) / stats.norm.ppf(1-((1-percent)/2))

    sm_mean = np.exp(sm_log_mean)
    sm_ci_low = np.exp(sm_log_ci_low)
    sm_ci_up = np.exp(sm_log_ci_up)
    plot_vals = [sm_ci_low, sm_mean, sm_ci_up]

    z = np.arange(-4, 4, 0.01)
    pred_vals = np.exp(sm_log_mean + (sm_log_se * z))
    prob = stats.lognorm.pdf(pred_vals, s=sm_log_se, scale=sm_mean)
    plot_probs = stats.lognorm.pdf(plot_vals, s=sm_log_se, scale=sm_mean)

    vals = {
        'pred_vals': pred_vals, 
        'prob': prob,
        'plot_vals': plot_vals,
        'plot_probs': plot_probs
    }
    return vals
